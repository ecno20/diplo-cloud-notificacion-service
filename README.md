# DIPLO-CLOUD-NOTIFICACION-SERVICE
Implementación de notificación en microservicio de DIPLO-CLOUD
## Proyecto
Implementation of  microservice for the disco-notification application. The notification microservice provides the following functionalities:
- Add/delete user
- dirección
- número de telefóno/correo
